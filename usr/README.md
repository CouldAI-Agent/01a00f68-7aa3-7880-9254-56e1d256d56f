# MySchoolWork

MySchoolWork is a mobile-first Flutter application designed for early learners (specifically modeled around a South African Grade 2 curriculum). The goal is to provide a highly accessible, child-friendly environment for practicing foundational skills like Numeracy.

## Features
*   **Data-Driven Curriculum:** Navigate dynamically through Grades, Subjects, Terms, Weeks, and Activities.
*   **Interactive Quizzes:** Supports multiple-choice, text-entry, and numeric-entry questions.
*   **Child-Friendly UI:** Features large tap targets, clear fonts, and positive reinforcement.
*   **Progress Tracking:** Visual indicators of progress through the current activity.
*   **Helpful Hints:** Incorrect answers trigger simple, constructive hints to guide the learner.

## Getting Started

1. Ensure you have Flutter installed.
2. Clone the repository and navigate to the project directory.
3. Run `flutter pub get` to fetch dependencies.
4. Run `flutter run` to launch the application.
